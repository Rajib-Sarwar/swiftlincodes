# Objective-C Interoperability

An original Swiftlin integration lab: Swift calls a typed Objective-C note store, then an Objective-C function calls a Swift formatter through its generated header. The service remains intact behind a small adapter.

- `Exercises`: three standard Swift boundary exercises, starter/final playgrounds. They do not run the Objective-C runtime in the browser.
- `Projects/starter`: runnable mixed-language app with four focused TODOs.
- `Projects/final`: complete app and 17 real cross-language verification checks.

Open each project's README for requirements and commands. This chapter is companion folder 13 (following the earlier Protocols practice folder); it corresponds to the website's Objective-C Interoperability topic.
