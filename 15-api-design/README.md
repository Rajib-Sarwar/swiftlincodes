# API Design — Saved Items Lab

A mobile saved-items screen backed by a separate Swift package. Learn to specify behavior, constrain mutations, document errors, and evolve call sites safely.

- `Projects/starter`: buildable teaching app with three explicit TODOs and intentionally failing contract tests.
- `Projects/final`: completed app and twelve consumer-facing tests.
- `Exercises`: three independent standard Swift challenges, each with starter/final playgrounds.

Use Xcode 16+ / Swift 6. The iOS app requires iOS 17.6+. Package tests also run on macOS 13+. No remote packages or credentials are required. Download archives preserve both app and library folders.
