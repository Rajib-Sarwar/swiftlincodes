# Functional Reactive Programming with Combine

Live Search Lab extends higher-order transformations into events over time.

- `Exercises/`: three browser-compatible standard Swift state exercises, not a Combine implementation.
- `CombineLab/`: a real Combine starter/final playground for macOS/Xcode.
- `Projects/starter` and `Projects/final`: SwiftUI app, injected Combine pipeline and twelve deterministic tests.
- [Starter download](../downloads/12-functional-reactive-programming-starter.zip) · [Final download](../downloads/12-functional-reactive-programming-final.zip).

Browser exercises make decision rules testable. Real operator behavior, subscriptions, cancellation, and scheduling are learned in CombineLab and the project on Apple platforms.
