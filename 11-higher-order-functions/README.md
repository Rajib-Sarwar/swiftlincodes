# Higher-Order Functions

Learn through a notification inbox: select a transformation by its output shape, preserve import failures, aggregate with reduce(into:), sort with a lawful comparator, and capture a reusable policy.

- `Exercises/`: three self-contained starter/final playground pairs, mirrored in the browser.
- `Projects/starter`: compiling Inbox Lab app with four TODOs and intentionally failing behavioral tests.
- `Projects/final`: complete app and ten behavioral tests.
- Downloads: [starter](../downloads/11-higher-order-functions-starter.zip) · [final](../downloads/11-higher-order-functions-final.zip).

Start with the website Learn page, solve the playgrounds, then build Inbox Lab in Xcode and use the interview questions to explain your decisions. See each project README for setup and acceptance criteria.
