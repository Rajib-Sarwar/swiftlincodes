# Codable: Library Sync

Original Swiftlin examples connecting data contracts, interview reasoning, and a mobile project.

- Exercises: presence policy, validated duration, nested rename request; each has starter and final playgrounds.
- Projects/starter: builds with clearly marked TODOs; contract tests intentionally fail until completed.
- Projects/final: complete SwiftUI fixture importer and real disk cache, with contract tests.
- Downloads: ../downloads/09-codable-starter.zip and ../downloads/09-codable-final.zip.

The website teaches the same models. No backend, secrets, network access, third-party dependencies, or encryption claims are involved. Screenshots remain explicitly labeled placeholders in the walkthrough.
