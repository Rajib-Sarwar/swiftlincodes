# Instrumentation

Original Swiftlin Catalog Performance Lab: a controlled CPU experiment, ImageIO preview sizing, callback lifetime investigation, and named signpost intervals.

- Three standard Swift exercise playgrounds teach decoded-size budgets, elapsed-time summaries, and interval correlation. The browser is not Instruments.
- Xcode starter/final projects contain a preserved baseline and four focused TODOs.
- Twelve deterministic tests verify behavior, not benchmark thresholds.
- Each project includes an unfilled PROFILE-REPORT.md for real-device evidence.

Core Data and build-time investigation are covered in the website as separate diagnostic workflows; this project has no persistent store.
