# Types, Values & Mutation

Reference code for the Swiftlin **Types, Values & Mutation** tutorial.

## Structure

```text
02-types-values-mutation/
├── Exercises/
│   ├── start.playground/
│   └── final.playground/
└── Projects/
    ├── starter/
    └── final/
```

### Exercises

- `Exercises/start.playground` contains the chapter challenges without solutions.
- `Exercises/final.playground` contains the completed solutions.
- Each playground includes a `Sources/ChapterTypes.swift` file with the supporting types used by the exercises.

### Projects

- `Projects/starter` will contain the starter SwiftUI project for the chapter build-along.
- `Projects/final` will contain the completed project.
