# Exercises

Open each starter.playground in Xcode, complete the TODOs, then compare final.playground. These mirror the website exercises. No network service is required.

1. **Keep the chosen receipt’s type** — Generic functions & inference
2. **Compare receipts from different sources** — Associated types & where
3. **Mix source types without losing receipt information** — Constrained existentials

Run each playground independently; supporting declarations are intentionally repeated.
