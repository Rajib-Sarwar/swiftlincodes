# Unsafe Swift & Memory

Original Swiftlin exercises and Packet Lab project. Three exercises each include starter/final playgrounds. Projects/starter builds with TODOs; Projects/final completes the checked decoder and tests.

Downloads are maintained in ../downloads/10-unsafe-starter.zip and ../downloads/10-unsafe-final.zip. The format is a local simulated sensor packet, not a real device protocol. Unsafe code is kept inside documented bounds and lifetime contracts; no examples intentionally trigger undefined behavior.
